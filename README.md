# Smart Task Tracker

Cloud Computing Final Project

## Team Members

- Sebastian Garcia
- Josue Canales

## Overview

A cloud-based task management application that allows users to create, update, and track tasks. Task data will be stored using MongoDB and deployed on AWS.

## Tech Stack

Frontend:
- HTML
- CSS
- JavaScript
- Bootstrap

Backend:
- Node.js
- Express.js
- MongoDB

Cloud:
- AWS EC2

## Project Goals

- Learn MongoDB and NoSQL databases
- Build a CRUD-based web application
- Deploy an application to the cloud
